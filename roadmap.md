# Roadmap MartCoin

## Fase 1 – Fundação (2025)

- [x] Criação da identidade do projeto (nome, logo, narrativa)
- [x] Lançamento do site oficial: [martcoin.carrd.co](https://martcoin.carrd.co)
- [x] Criação do repositório no GitHub
- [x] Publicação do README.md e whitepaper inicial
- [ ] Criação das redes sociais (Twitter/X, Instagram, Discord, Telegram)

## Fase 2 – Desenvolvimento Inicial (2025)

- [ ] Desenvolvimento do contrato inteligente (ERC-20)
- [ ] Testes na testnet (Ethereum ou Polygon)
- [ ] Auditoria inicial do contrato
- [ ] Criação da comunidade oficial (Discord/Telegram)
- [ ] Pré-venda privada para apoiadores pioneiros

## Fase 3 – Validação e Crescimento (2025–2026)

- [ ] Publicação da versão 1.0 do whitepaper (com revisões técnicas e visuais)
- [ ] Listagem em exchanges descentralizadas (Uniswap, PancakeSwap)
- [ ] Parcerias com simuladores de colônia marciana na Terra
- [ ] Marketing voltado ao setor aeroespacial e tecnológico

## Fase 4 – Consolidação Espacial (2026–2030)

- [ ] Parcerias com projetos reais de colonização (SpaceX, NASA, ESA, etc.)
- [ ] Uso simbólico em missões simuladas
- [ ] Testes de transações com dispositivos remotos e ambientes isolados

## Fase 5 – Ativação Marciana (2030+)

- [ ] Uso oficial em habitats marcianos
- [ ] Financiamento de módulos de oxigênio com MartCoin
- [ ] Sistema de governança descentralizada marciana (DAO)
- [ ] MartCoin como base de uma economia funcional em Marte

---

**Este roadmap será atualizado conforme o projeto avança.**  
A MartCoin não é apenas uma moeda: é um passo para o futuro da humanidade fora da Terra.
